# Firebase Setup Instructions

The code for Firebase Authentication and mandatory biometric security has been successfully added to the WOLOW Lite app. However, to complete the setup, you need to configure Firebase in your project.

## Step-by-Step Setup

### 1. Install Firebase CLI (if not already installed)
```bash
npm install -g firebase-tools
```
*(You already have Firebase CLI v15.19.1 installed)*

### 2. Login to Firebase
```bash
firebase login
```
This will open a browser window for you to authenticate with your Google account. Follow the prompts to log in.

### 3. Create a Firebase Project (or use existing)
You can create a project via:
- Firebase Console: https://console.firebase.google.com/
- Or via CLI: `firebase projects:create`

### 4. Configure Your Flutter App with Firebase
Run the Firebase configuration wizard:
```bash
flutterfire configure
```
Or use the full path if needed:
```
C:\Users\kdrak\AppData\Local\Pub\Cache\bin\flutterfire.bat configure
```

During the setup:
- Select the Firebase project you created (or create a new one)
- Select the platforms: Android, iOS, macOS, Windows (as applicable)
- Accept the suggested Android package name: `com.wolow.wolow_lite`
- Accept the suggested iOS bundle ID: `com.wolow.wolowLite`
- The tool will generate `lib/firebase_options.dart` and update platform configuration files

### 5. Enable Authentication Providers
In the Firebase Console:
1. Go to **Authentication** → **Sign-in method**
2. Enable:
   - Email/Password
   - Google (configure a support email)
   - Facebook (you'll need to create a Facebook App at https://developers.facebook.com/ and add the OAuth redirect URI: `https://<your-project-id>.firebaseapp.com/__/auth/handler`)

### 6. Download Configuration Files
After running `flutterfire configure`:
- `google-services.json` will be placed in `android/app/`
- `GoogleService-Info.plist` will be placed in `ios/Runner/`

### 7. Build and Run
```bash
flutter pub get
flutter run
```

## Verification
When you run the app:
1. You should see the login screen (not the device list)
2. Sign in with email/password, Google, or Facebook
3. After successful login, you will be prompted to enable biometric authentication (fingerprint/face)
4. Once biometrics are enabled, you'll proceed to the main device list
5. On subsequent app launches, you'll be prompted for biometric authentication before accessing the app

## Important Notes
- The biometric authentication is **mandatory** - users cannot skip the setup screen
- If a device lacks biometric hardware, the app will skip the biometric check and proceed directly to the main screen (for compatibility)
- Firebase handles token refresh automatically - no custom token management needed
- All existing WOLOW functionality (device control, Wake-on-LAN, audio controls) remains intact and works after authentication

## Troubleshooting
If you encounter issues:
- Ensure `google-services.json` and `GoogleService-Info.plist` are in the correct locations
- Run `flutter clean` and `flutter pub get` if you see build errors
- Check that your Firebase project ID matches what's in `firebase_options.dart`
- For Android: ensure you've added the SHA-1 certificate fingerprint in Firebase Project Settings (needed for Google Sign-in)
- For iOS: ensure you've added the reversed client ID as a URL scheme in `Info.plist`
