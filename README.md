# WOLOW Lite

Remote PC control from your phone. Wake-on-LAN, audio switching, system monitoring, app launcher, and more — all over your local network.

## What It Does

- **Wake-on-LAN** — Turn on your PC from your phone
- **Power controls** — Reboot, shutdown, sleep, lock
- **Audio control** — Switch output devices, adjust volume, mute/unmute
- **System monitoring** — Live CPU, RAM, and disk usage
- **Process list** — See what's running on your PC
- **App launcher** — Fuzzy-search and launch installed apps
- **Media controls** — Play/pause, next, previous, volume
- **Custom commands** — Run any shell command remotely
- **File transfer** — Upload/download files between phone and PC

## Architecture

```
┌──────────────┐     HTTP/UDP      ┌──────────────────┐
│  Flutter App  │ ◄──────────────► │  Python Agent     │
│  (Phone)      │   LAN (port 8220) │  (PC)             │
└──────────────┘                   └──────────────────┘
```

- **Flutter app** (`lib/main.dart`) — Single-file mobile app with iOS-style dark UI
- **Python agent** (`pc_agent/`) — Flask HTTP server with UDP discovery listener

## Setup

### PC (Windows)

1. Install [Python 3.10+](https://www.python.org/downloads/) (check "Add to PATH")
2. Right-click `setup.bat` → **Run as administrator**
3. Done. The agent runs as a background scheduled task.

### PC (Linux/macOS)

```bash
sudo bash setup.sh
```

### Phone

1. Build and install the Flutter app
2. Make sure your phone and PC are on the same WiFi
3. Tap **+** → **Scan Network** — your PC appears automatically
4. Tap **Add**

## Agent Endpoints

| Endpoint | Method | Auth | Description |
|----------|--------|------|-------------|
| `/status` | GET | No | Health check, hostname, platform |
| `/action` | POST | Yes | Execute: reboot, shutdown, sleep, hibernate, lock |
| `/register` | POST | Yes | Register phone as device owner |
| `/unregister` | POST | Yes | Remove device owner |
| `/stats` | GET | Yes | CPU, RAM, disk usage |
| `/processes` | GET | Yes | Top processes by CPU |
| `/audio-devices` | GET | Yes | List audio output devices |
| `/audio-device` | POST | Yes | Switch default audio device |
| `/volume` | GET/POST | Yes | Get/set volume, mute/unmute |
| `/media` | POST | Yes | Send media key (play, next, etc.) |
| `/apps` | GET | Yes | List installed apps |
| `/apps/launch` | POST | Yes | Launch app by path |
| `/apps/open` | POST | Yes | Launch app by name (fuzzy match) |
| `/commands` | GET/POST | Yes | List/add custom commands |
| `/commands/run` | POST | Yes | Run a custom command |
| `/files` | GET | Yes | List files in transfer directory |
| `/files/upload` | POST | Yes | Upload a file |
| `/files/download` | GET | Yes | Download a file |

Auth: `X-Token` header or `token` in JSON body.

## Configuration

Agent config is in `pc_agent/config.yaml` (generated by setup, not committed):

```yaml
server:
  host: 0.0.0.0
  port: 8220
  token: <auto-generated>
logging:
  level: INFO
```

Environment variables override config: `WOLOW_TOKEN`, `WOLOW_PORT`.
